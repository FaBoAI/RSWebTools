# RobStride 私有プロトコル 要約

本アプリの実装根拠。すべて公式ユーザーマニュアル (RS00〜RS06, 2025-11-12 版) の記載に基づく。

## 1. USB-CAN アダプタのシリアルフレーム

純正 USB-CAN モジュール (CH340 + GD32) は AT モードで動作し、CAN フレームを次の形式で包む。

```
'A' 'T' | ext_id<<3 | 0x04 (4 バイト BE) | DLC (1) | data[DLC] | CR LF
0x41 0x54                                                        0x0D 0x0A
```

下位 3bit の `0x04` は拡張フレーム (IDE) を示すフラグ。受信時は 3bit 右シフトで実 ID に戻す。
シリアル速度の既定は 921600bps。

**マニュアル記載の実例:**

```
41 54 90 07 e8 0c 08 05 70 00 00 01 00 00 00 0d 0a
   └─ヘッダ  └─ ID ──┘ └DLC └──────── data ────────┘ └─尾
```

`0x9007E80C >> 3 = 0x1200FD01` → 通信タイプ `0x12` (書込) / ホスト `0x00FD` / モータ `0x01`、
データは index `0x7005` (run_mode) に値 `1` を書く指令。

この 1 例が本実装の回帰テストになっている (`tests/test_protocol.py`)。

## 2. 29bit 拡張 ID

| ビット | 内容 |
|---|---|
| 28–24 | 通信タイプ (5bit) |
| 23–8 | データ領域2 (16bit) — 送信時はホスト CAN_ID、応答時は送信元情報 |
| 7–0 | 宛先 CAN_ID |

応答フレームでは bit15–8 が送信元モータの CAN_ID、bit7–0 がホスト CAN_ID になる。

## 3. 通信タイプ

| 値 | 内容 | データ部 |
|---|---|---|
| 0x00 | デバイス ID 取得 | 0 / 応答に 64bit MCU 固有 ID |
| 0x01 | 運動制御指令 | 下記 §4 |
| 0x02 | フィードバック | 下記 §5 |
| 0x03 | 運転許可 | 全 0 |
| 0x04 | 停止 | 全 0 (`Byte[0]=1` で故障クリア) |
| 0x06 | 機械原点設定 | `Byte[0]=1` |
| 0x07 | CAN_ID 変更 | 新 ID を拡張 ID の bit23–16 に載せる |
| 0x11 | パラメータ読出 | `Byte0-1`=index / 応答の `Byte4-7`=値 |
| 0x12 | パラメータ書込 | `Byte0-1`=index, `Byte4-7`=値 (電源断で消失) |
| 0x15 | 故障通知 | `Byte0-3`=故障値, `Byte4-7`=警告値 |
| 0x16 | 保存 | `01 02 03 04 05 06 07 08` |
| 0x17 | CAN ボーレート変更 | `01…06 F_CMD` (1:1M 2:500K 3:250K 4:125K) |
| 0x18 | 能動送信 ON/OFF | `01…06 F_CMD` (0:無効 1:有効) |
| 0x19 | プロトコル変更 | `01…06 F_CMD` (0:私有 1:CANopen 2:MIT) |
| 0x1A | バージョン読出 | `Byte0=0x00, Byte1=0xC4` |

0x16〜0x19 の変更は電源再投入で反映される。

## 4. 運動制御 (通信タイプ 1)

トルクは **データ部ではなく拡張 ID のデータ領域2** に入る。データ部は 16bit 値 4 つを
**上位バイト先行 (ビッグエンディアン)** で並べる。

| バイト | 内容 | レンジ |
|---|---|---|
| ID bit23-8 | トルク t_ff | `T_MIN`〜`T_MAX` |
| 0–1 | 目標位置 p_set | `P_MIN`〜`P_MAX` |
| 2–3 | 目標速度 v_set | `V_MIN`〜`V_MAX` |
| 4–5 | Kp | `0`〜`KP_MAX` |
| 6–7 | Kd | `0`〜`KD_MAX` |

制御則: `t_ref = Kd·(v_set − v_act) + Kp·(p_set − p_act) + t_ff`

スケーリング式 (マニュアルの `float_to_uint` と同一、**分母は 2^bits − 1**):

```c
return (int)((x - x_min) * ((float)((1 << bits) - 1)) / (x_max - x_min));
```

## 5. フィードバック (通信タイプ 2 / 24)

拡張 ID:

| ビット | 内容 |
|---|---|
| 15–8 | モータ CAN_ID |
| 21–16 | 故障ビット (16:低電圧 17:三相電流 18:過温度 19:磁気エンコーダ 20:ロック過負荷 21:未校正) |
| 23–22 | モードステータス (0:Reset 1:Cali 2:Run) |

データ部 (すべて上位バイト先行):

| バイト | 内容 | 換算 |
|---|---|---|
| 0–1 | 角度 | `[0,65535]` → `P_MIN`〜`P_MAX` |
| 2–3 | 角速度 | `[0,65535]` → `V_MIN`〜`V_MAX` |
| 4–5 | トルク | `[0,65535]` → `T_MIN`〜`T_MAX` |
| 6–7 | 温度 | 値 ÷ 10 [℃] |

## 6. パラメータ表 (0x11 / 0x12)

値は index の型に関わらず `Byte4-7` の 4 バイト枠に**リトルエンディアン**で載る
(uint8 なら `Byte4` のみ使用)。

| index | 名称 | 型 | 備考 |
|---|---|---|---|
| 0x7005 | run_mode | uint8 | 0:運動制御 1:位置PP 2:速度 3:電流 5:位置CSP |
| 0x7006 | iq_ref | float | 電流モードの Iq 指令 |
| 0x700A | spd_ref | float | 速度モードの速度指令 |
| 0x700B | limit_torque | float | トルク制限 |
| 0x7010 / 0x7011 | cur_kp / cur_ki | float | 既定 0.17 / 0.012 |
| 0x7014 | cur_filt_gain | float | 既定 0.1 |
| 0x7016 | loc_ref | float | 位置モードの角度指令 [rad] |
| 0x7017 | limit_spd | float | CSP モードの速度制限 |
| 0x7018 | limit_cur | float | 速度/位置モードの電流制限 |
| 0x7019 | mechPos | float | 出力軸機械角 (R) |
| 0x701A | iqf | float | Iq フィルタ後 (R) |
| 0x701B | mechVel | float | 出力軸速度 (R) |
| 0x701C | VBUS | float | バス電圧 (R) |
| 0x701E | loc_kp | float | 既定 40 |
| 0x701F / 0x7020 | spd_kp / spd_ki | float | 既定 6 / 0.02 |
| 0x7021 | spd_filt_gain | float | 既定 0.1 |
| 0x7022 | acc_rad | float | 速度モード加速度、既定 20 |
| 0x7024 / 0x7025 | vel_max / acc_set | float | PP モード、既定 10 / 10 |
| 0x7026 | EPScan_time | uint16 | 能動送信周期。1=10ms、+1 ごとに +5ms |
| 0x7028 | canTimeout | uint32 | 20000=1s、0 で無効 |
| 0x7029 | zero_sta | uint8 | 0:電源投入時 0〜2π / 1:−π〜π |
| 0x702A | damper | uint8 | 1 で電源断時のダンピング無効 |
| 0x702B | add_offset | float | 原点オフセット [rad] |

0x20xx 系 (不揮発の設定値) はマニュアルに表が画像でしか載っておらず本実装では
固定表を持たない。UI の「インデックス調査」で実機から読み出して確認できる。

## 7. 制御モードの手順

| モード | 手順 |
|---|---|
| 運動制御 | 運転許可 (0x03) → 運動制御指令 (0x01) を周期送信 |
| 電流 | run_mode=3 → 運転許可 → iq_ref |
| 速度 | run_mode=2 → 運転許可 → limit_cur → acc_rad → spd_ref |
| 位置 CSP | run_mode=5 → 運転許可 → limit_spd → loc_ref |
| 位置 PP | run_mode=1 → 運転許可 → vel_max → acc_set → loc_ref |
